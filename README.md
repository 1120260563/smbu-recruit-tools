# SMBU-CA 招新报名数据清洗与统计工具

深圳北理莫斯科大学计算机协会（SMBU·CA）招新报名表（问卷导出 CSV）的
读入概览、校验清洗、统计分析小工具。纯 Python 标准库实现，开箱即用。

> 按三个需求分三次 PR 迭代开发：
> - PR #1：读入与概览（已完成）
> - PR #2：校验与清洗 —— 问题清单导出（已完成）
> - PR #3：统计与导出 —— 按志愿分组统计、导出清洗后数据（已完成）

## 需求1：读入与概览

读入报名表 CSV，打印一份概览：总行数、每列空值数、完全重复的行。

```bash
python recruit_tool.py overview --input <报名表CSV路径>
```

### CSV 格式要求

- 编码：UTF-8（带或不带 BOM 均可，工具自动兼容）
- 表头列名必须包含以下六列（顺序不限）：
  `姓名`、`学号`、`邮箱`、`志愿1`、`志愿2`、`推荐人`
- 缺少任一列会报错退出；多余的列会被忽略

### 概览输出说明

- **数据行数**：不含表头的记录条数
- **每列空值统计**：该列为空（去除首尾空白后为空串）的行数
- **完全重复的行**：六列值完全一致视为重复，报告重复组数、每组出现次数与文件行号、
  首行姓名/学号便于人工定位

### 处理假设（需求1）

1. **空白处理**：每个字段自动去除首尾空白后再比较，避免问卷导出多余空格误判
2. **空值定义**：去除首尾空白后为空串即视为「空值」（即未填）
3. **完全重复**：以六列值是否完全一致判定；多组重复都会列出

## 需求2：校验与清洗

对报名数据逐行校验，把有问题的行单独导出一份「问题清单」（并写明每行的问题原因），
**不修改原文件**；清洗后、通过校验的行用于需求3的统计。

```bash
python recruit_tool.py validate --input <报名表CSV路径> [--outdir data/output]
```

### 校验规则

| 规则 | 判定 |
| --- | --- |
| 学号必须为纯数字 | 学号为空 →「学号缺失」；含非数字字符 →「学号非纯数字」 |
| 邮箱必须为 学号@smbu.edu.cn | 学号有效时校验：邮箱为空 →「邮箱缺失」；不匹配（大小写不敏感） →「邮箱与学号不匹配」 |
| 重复报名 | 同一学号出现多次即重复：完全相同的行保留首条、其余标记；学号相同但内容不同的全部标记 |

一行可能同时命中多条规则，问题原因以「；」分隔全部列出。

### 问题清单格式

输出文件 `data/output/问题清单.csv`，列为：`行号、姓名、学号、邮箱、问题原因`。
`行号` 为该行在原 CSV 中的行号（表头为第 1 行，数据从第 2 行起），便于人工回溯原文件。

### 清洗策略与假设（需求2）

1. **学号位数**：SMBU 学号通常为 10 位（如 `1120260002`），但本工具**不校验位数**，
   只校验是否纯数字。原因：规范原文只要求「学号必须是纯数字」，
   避免把非 10 位学号误判为问题（如 11 位纯数字 `11202601234` 视为正常）。
   若需强制位数，可在源码 `validate_rows` 中放宽/收紧。
2. **邮箱大小写**：邮箱域名与学号部分大小写不敏感（`@SMBU.EDU.CN` 与 `@smbu.edu.cn` 视为一致）。
3. **学号无效时不重复校验邮箱**：学号缺失或非纯数字时，邮箱规则无法成立，
   只标学号问题，不再重复标记邮箱。
4. **重复报名处理**：完全相同的重复行保留首条报名、其余进问题清单
   （视为重复提交）；学号相同但内容不同的全部进问题清单（需人工判断保留哪条）。
   故「清洗后数据」不含任何重复学号。
5. **空白处理**：同需求1，字段去除首尾空白后再校验。
6. **不修改原文件**：问题行单独导出，原 CSV 保持不变。

## 需求3：统计与导出

基于需求2的清洗结果（已剔除问题行），进行统计并导出清洗后的干净数据。

```bash
python recruit_tool.py stats --input <报名表CSV路径> [--outdir data/output]
```

该命令会内部执行校验（复用需求2规则）得到清洗后数据，再统计并导出。

### 输出文件

| 文件 | 内容 |
| --- | --- |
| `data/output/清洗后报名表.csv` | 通过校验的干净数据（六列原样导出） |
| `data/output/第一志愿统计.csv` | 按第一志愿分组的人数汇总（人数降序，「未填」置末） |
| `data/output/志愿填写情况.csv` | 两志愿都填 / 只填第一 / 只填第二 / 都没填 的人数 |

### 统计说明与假设（需求3）

1. **统计基于清洗后数据**：先按需求2规则剔除问题行，再统计；问题行不参与统计。
2. **按第一志愿分组**：以 `志愿1` 为分组键；`志愿1` 为空的归入「未填」组并置于汇总表末尾。
3. **志愿填写情况四类**：
   - 两个志愿都填：`志愿1` 与 `志愿2` 均非空
   - 只填第一志愿：仅 `志愿1` 非空
   - 只填第二志愿：仅 `志愿2` 非空
   - 两个志愿都没填：两者均为空
4. **导出编码**：输出 CSV 均为 UTF-8 with BOM，Excel 直接打开不乱码。

## 完整使用流程

```bash
# 1) 概览：先看数据全貌
python recruit_tool.py overview --input data/raw/2026-recruit-signup.csv

# 2) 校验：导出问题清单，人工核实
python recruit_tool.py validate --input data/raw/2026-recruit-signup.csv

# 3) 统计：基于清洗后数据统计并导出
python recruit_tool.py stats --input data/raw/2026-recruit-signup.csv
```

> 替换 `--input` 为你自己的报名表 CSV 即可；输出默认写入 `data/output/`，
> 可用 `--outdir` 指定其他目录。
